## PyMEX Examples

1. [`monolayer_WSe2`](./monolayer_WSe2): Calculate intralayer excitons in monolayer WSe₂. This is the simplest example for 2D materials.

2. [`MoSe2_WSe2`](./MoSe2_WSe2): Calculate excitons in a MoSe₂/WSe₂ heterobilayer. The conduction and valence bands come from different materials, forming a type-II heterojunction. The lowest-energy excitons are interlayer excitons.

3. [`Moire_WSe2`](./Moire_WSe2): Calculate intralayer excitons in WSe₂ with moiré-induced atomic rearrangements.

4. [`MacvsHPC`](./MacvsHPC): Run PyMEX on a Mac and an HPC system and compare the two setups.

Start with `monolayer_WSe2` if you're new to PyMEX, then move to the heterobilayer and moiré examples as you become familiar with the config format.

A paper with more technical details, scaling, and examples is under preparation.
